You are helping build a new skill for NemoClaw — a personal portfolio intelligence Telegram bot.

## Project layout

- `main.py` — Telegram poll loop + scheduler + skill router (auto-discovers skills)
- `core/` — shared modules (see below)
- `skills/` — one file per skill, auto-discovered at startup
- `prompts/` — LLM prompt templates (.txt with `{placeholder}` variables)
- `config/` — portfolio.yaml, theses.yaml, keywords.yaml, news_sources.yaml
- `data/` — news_log.db (SQLite, WAL mode)

## Skill file anatomy

Every skill is a Python module in `skills/`. Auto-discovery reads these module-level constants:

```python
"""Skill N: Short description."""

import logging
from core import config_loader, llm_client, telegram_bot

logger = logging.getLogger(__name__)

# ── Required for auto-discovery ──────────────────────────────────────
COMMANDS = [
    # exact match (case-insensitive)
    {"type": "exact", "pattern": "my command", "call": "my_function"},
    # prefix match — text after prefix passed as argument
    {"type": "prefix", "pattern": "my command ", "call": "my_function_with_arg"},
    # regex match — group(1) passed as argument
    {"type": "regex", "pattern": r"(?i)my pattern (\w+)", "call": "my_function_with_arg", "args": "upper"},
]
# args modes: "upper" (uppercase group 1), "raw" (raw group 1), omit for no arg

SCHEDULE = [
    # interval-based (reads from schedule_config() or uses default)
    {"func": "my_scheduled_func", "interval": "my_poll_minutes", "default": 60},
    # time-based (days = list of weekday names, or ["daily"])
    {"func": "my_daily_func", "days": ["monday", "tuesday", "wednesday", "thursday", "friday"], "at": "07:00"},
]

HELP_ORDER = 10   # lower = appears higher in help output
HELP = (
    "*My Section*\n"
    "`my command` — what it does\n"
    "`my command <arg>` — variant with argument"
)
# Set HELP = None to hide from help output entirely

# ── Implementation ────────────────────────────────────────────────────

def my_function() -> str:
    ...
    return "result text (Telegram Markdown)"

def my_function_with_arg(arg: str) -> str:
    ...
    return "result text"
```

## Prompt template anatomy

If the skill calls the LLM, create `prompts/my_skill.txt`:

```
You are a [role]. [Task description].

{portfolio_context}

[Other static context]

DATA:
{data_json}

FORMAT:
[Exact output format instruction]
```

Inject in the skill using `.replace()` (NOT `.format()`) for all placeholders:
```python
from pathlib import Path

PROMPT_PATH = Path(__file__).parent.parent / "prompts" / "my_skill.txt"

def generate() -> str:
    with open(PROMPT_PATH) as f:
        template = f.read()
    prompt = template.replace("{portfolio_context}", config_loader.portfolio_scoring_context())
    prompt = prompt.replace("{data_json}", json.dumps(data, default=str))
    return llm_client.chat([{"role": "user", "content": prompt}], temperature=0.4, max_tokens=1024)
```

**IMPORTANT — brace escaping**: If the skill uses `.format()` anywhere on the prompt string (not just `.replace()`), you must escape braces in the portfolio context first:
```python
safe_ctx = config_loader.portfolio_scoring_context().replace("{", "{{").replace("}", "}}")
raw = template.replace("{portfolio_context}", safe_ctx)
prompt = raw.format(other_var=value)
```

## Critical rules

- **Telegram Markdown**: legacy `parse_mode="Markdown"`. Use `*bold*`, `_italic_`, `` `code` ``. Do NOT use MarkdownV2 syntax.
- **Synchronous only** — no async/await anywhere.
- **No new dependencies** without confirming first.
- **Logging**: module-level `logger = logging.getLogger(__name__)`. Log with `logger.info/warning/error`.
- **Private functions**: prefix with `_`.
- **Constants**: UPPERCASE at module level.
- **Error handling**: wrap LLM calls in try/except, return a user-facing error string.
- **Scheduled functions** must call `telegram_bot.send()` directly (not return a string).
- **On-demand functions** (triggered by Telegram command) must return a string.
